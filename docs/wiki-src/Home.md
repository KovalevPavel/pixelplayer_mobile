# Home

Pixelplayer is a modular Kotlin Multiplatform music player with a shared Compose UI and platform-specific hosts for Android and iOS. It is designed for projects that need a clean split between app shell, features, networking, storage, and playback.

This Wiki is useful for:

- developers working on architecture, features, and build flows
- reviewers who need a quick map of the repository
- product stakeholders who need a concise overview of the implemented user flows
