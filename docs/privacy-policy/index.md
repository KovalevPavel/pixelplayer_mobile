# Privacy Policy for Pixelplayer Demo

Last updated: April 28, 2026

Pixelplayer Demo is a demonstration music player application published by Pavel Kovalev.

## Accounts

Pixelplayer Demo uses one shared demonstration account. Users do not register personal accounts in the app and do not create account data through the app.

## Data Collection

Pixelplayer Demo does not use advertising, analytics, tracking SDKs, geolocation, contacts, camera, microphone, or similar device data collection features.

## Data Used by the App

The app uses the server endpoint and demo credentials only to connect to the selected demo server and play demo content. Credentials and app settings are stored locally on the user's device. Sensitive credentials are stored in protected local storage.

The username and authorization token are kept locally until the user logs out, changes the server, or uninstalls the app. Logging out clears the username and authorization token.

The server endpoint is kept locally after logout so the user can return to the same server without entering the address again. The endpoint is removed when the user selects Change server and confirms the server change, or when the app is uninstalled.

## Account Deletion

Account deletion is not applicable to Pixelplayer Demo because users cannot create personal accounts in the app. The shared demonstration account is managed by the developer and is not tied to an individual user.
